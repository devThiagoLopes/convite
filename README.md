# lembrete
Página de lembrete digital para os convidados já confirmados da festa de 15 anos (versão derivada do convite original).

## Estrutura de páginas
- `index.html` — capa/envelope ("Toque para abrir"). É o `index.html` de propósito: no GitHub Pages (ou qualquer host), é a página que abre por padrão na raiz do site.
- `lembrete.html` — conteúdo do lembrete (datas, traje, ícones). Entra sozinho com a animação dos cantos assim que carrega.
- `presentes.html` — lista de sugestões de presentes. O botão "Voltar" retorna para `lembrete.html`.
